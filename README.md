# Urgent
```mermaid
flowchart TD
    A[They say it is urgent]-->B{How they reach you?}
    B-->|Message|C[Do not reply right away or do not reply at all]
    B-->|Call|D[Answer the call but do not commit to anything, say follow up after the call]
```
